# Hangman Game 🎮

A simple command-line Hangman game built using Python as part of my CodeAlpha Python Programming Internship.

## 📌 Project Overview

The program randomly selects a word from a predefined list. The player guesses one letter at a time to reveal the hidden word.

The player has 6 lives and loses a life for every incorrect guess.

## ✨ Features

* Random word selection
* Hidden word display
* Letter-by-letter guessing
* Correct letter detection
* Wrong letter tracking
* 6 lives system
* Duplicate guess detection
* Input validation
* Uppercase/lowercase handling
* Win and Game Over conditions

## 🛠️ Technologies Used

* Python
* Random module
* Lists
* Tuples
* Loops
* Conditional statements
* Functions

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python hangman.py
```

5. Enter one letter at a time when prompted.

## 🎮 Example

```text
Welcome to Hangman!

Guess a letter: a
```
